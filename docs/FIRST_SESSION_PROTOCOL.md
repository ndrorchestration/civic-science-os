# First real-session protocol — Planet Hunters TESS

Status: READY FOR HUMAN EXECUTION / NO CLASSIFICATION AUTOMATION.

## Purpose

This protocol exists to exercise Civic Science OS v0.1.0 against one real citizen-science session without changing the scientific task or introducing external AI into classification.

## Before the session

1. Open the current Planet Hunters TESS project page and project-provided tutorial / field guide.
2. Confirm the project is still accepting classifications.
3. Note the local start time with timezone.
4. Do not ask ChatGPT, Gemini, another LLM, or an external vision/classification system to interpret any light curve or suggest a classification.
5. Keep this logger closed during the scientific judgment if that makes separation easier.

## During the session — HUMAN ONLY

- Use only your own judgment and project-provided materials for classifications.
- Do not automate clicks, labels, submissions, or answer generation.
- Do not send subject images, light curves, or classification questions to an external AI tool.
- If uncertain, use the project’s own guidance mechanisms.
- Do not change a decision because of this repository or its documentation.

## After the session

Record only process-level facts:

- start time and end time;
- number of classifications if the platform visibly reports it;
- uncertainty categories you noticed;
- procedural friction;
- learning notes;
- follow-up questions.

Do not claim accuracy, scientific impact, project endorsement, or successful exoplanet identification from participation alone.

## Suggested post-session capture

```text
Start time (with timezone):
End time (with timezone):
Classifications completed (if visible):
Ambiguity codes:

```

## Valid ambiguity codes

- LOW_SIGNAL
- STELLAR_VARIABILITY
- EDGE_EVENT
- MULTIPLE_CANDIDATES
- DATA_GAP_OR_ARTIFACT
- TUTORIAL_RULE_UNCERTAINTY
- SIMULATION_FEEDBACK
- OTHER

## Completion criterion

Session 1 is complete only when:
1. the classification activity was performed by the human contributor;
2. no external generative AI aided the scientific classification;
3. the resulting process facts are entered into the logger;
4. the logger validates the record;
5. the first real weekly/process review is generated.

Completion of this protocol establishes that the logger has been exercised on one real session. It does not establish classification skill or scientific impact.
